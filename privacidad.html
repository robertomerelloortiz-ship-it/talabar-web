Qué datos recogemos

Este sitio web utiliza Google Tag Manager y Google Analytics 4 para recopilar datos anónimos sobre el uso de la web: páginas visitadas, tiempo de visita, país de origen y dispositivo utilizado. Esta información se usa exclusivamente para mejorar el sitio y no permite identificar a ningún usuario de forma personal.

Si nos contactas por correo electrónico, los datos que facilites se usarán exclusivamente para atender tu consulta y no se cederán a terceros.

Cookies

Este sitio web utiliza únicamente cookies técnicas de Google Fonts, un servicio de tipografías de Google LLC que permite cargar las fuentes utilizadas en el diseño. Estas cookies son de carácter técnico, necesarias para el correcto funcionamiento visual del sitio, y no se emplean con fines publicitarios ni de seguimiento.

Puedes consultar la política de privacidad de Google en policies.google.com/privacy.

Si no deseas que se carguen estas fuentes externas, puedes deshabilitar el uso de cookies de terceros en la configuración de tu navegador, aunque esto podría afectar al aspecto visual del sitio.
